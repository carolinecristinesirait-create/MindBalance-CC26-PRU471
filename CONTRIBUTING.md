# Contributing

1. Create a branch from `main`.
2. Keep preprocessing formulas aligned with the training notebook and model contract.
3. Add or update tests for behavioral changes.
4. Run `python -m compileall app.py mindbalance` and `pytest -q`.
5. Avoid medical claims, diagnostic language, and treatment recommendations.
6. Never commit secrets or identifiable assessment data.
7. Open a pull request that explains the change, testing performed, and any model-impacting assumptions.
